VOXORA ACCESS — V25 FIXED VIEWPORT VOICE CONTROLS

This release corrects the voice-control dock positioning. In V24, the dock was moved upward whenever the footer entered the viewport. Because the offset used the footer's full height rather than its actual viewport position, the controls could appear near the middle of the screen.

1. FIXED VIEWPORT POSITIONING
   - Removed footer-visibility detection and footer-height-based dock offsets.
   - Rendered the assistant notice and control dock through a React portal attached to document.body. This prevents application layout containers from becoming the fixed-position containing block.
   - Anchored the dock to the bottom centre of the browser viewport with safe-area support.
   - Applied explicit fixed-position constraints and a global stacking order.
   - Retained responsive sizing and the measured dock height used by the scroll-to-top control.
   - Did not add bottom padding or artificial trailing space to the page footer.

2. PRESERVED FUNCTIONALITY
   - Preserved V24 echo cancellation, speech interruption, transcript echo filtering and half-duplex fallback.
   - Preserved the existing microphone states and Stop speaking control.
   - Preserved the Voxora logo in the footer.
   - No changes to document processing, account management, sharing, or resource permissions.

3. REGRESSION COVERAGE
   - Added a source contract verifying the control dock is portaled to document.body.
   - Added a source contract verifying fixed viewport positioning.
   - Updated the browser test to verify the dock remains at the same viewport-relative bottom position before and after scrolling.
   - Added a guard against reintroducing footer-dependent positioning.
