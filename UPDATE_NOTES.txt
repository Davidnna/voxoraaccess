VOXORA ACCESS — V26 DOCUMENT STRUCTURE AND SEMANTIC READING

BASELINE
- Built from the V25 source package, which the user confirmed deployed successfully.
- Voice assistant, echo handling, barge-in behaviour, fixed viewport controls, footer layout and footer branding are preserved. No changes were made to VoiceAssistant.jsx or the V25 voice-control positioning implementation.

DOCUMENT STRUCTURE IMPROVEMENTS
1. WORD DOCUMENTS
   - Resolve headings from built-in heading styles, inherited custom styles and explicit outline levels.
   - Preserve list type and nesting level from Word list styles and numbering definitions.
   - Preserve inline image descriptions in their position within paragraph content; provide a clear placeholder when a visual object has no alternative description.
   - Preserve consecutive explicitly marked repeating header rows, including multiple leading header rows.
   - Read physical table grid cells and retain detected horizontal/vertical merge spans without repeating merged-cell text.
   - Include available footnotes and endnotes in separate sections after the main body; disclose that their original inline reference positions are not recreated.
   - Continue to flag nested tables, floating text boxes, embedded charts/diagrams and review comments where content may be missing.

2. POWERPOINT PRESENTATIONS
   - Preserve bullet/numbered list type and nesting level where the slide XML exposes it.
   - Preserve merged table cell spans while continuing not to assume that the first row is a header.
   - Include available speaker notes after their slide content and flag that they may contain presenter-only information.
   - Continue to warn about uncertain slide object order, charts, SmartArt and images without alternative descriptions.

3. PDF DOCUMENTS
   - Request pypdf layout-mode text extraction for each page and fall back to standard extraction if layout mode is unavailable or fails.
   - Keep explicit warnings that this does not validate the PDF tag tree or guarantee the reading order of complex multi-column/floating content.
   - Preserve OCR fallback behaviour and scanned-page status handling.

4. TABLE RENDERING
   - Support multiple explicit header rows.
   - Render detected colspan and rowspan metadata in the reading view.
   - Build nested HTML lists from preserved list levels.
   - Render speaker notes and missing-image-description placeholders as accessible content.
   - Account for table row and column separators when enforcing the stored text limit.

5. STUDENT-FACING ABSTRACTION
   - Hide internal extraction-method names from the resource API and reading interface.
   - Use task-oriented wording such as "Prepare reading view" and plain-language document notes.
   - Keep detailed implementation information in developer documentation, not the student interface.

REGRESSION COVERAGE
- Added tests for custom Word headings, outline levels, nested lists, inline image descriptions, multiple header rows, merged table spans, footnotes, PowerPoint list levels, speaker notes, PowerPoint merged cells, PDF layout extraction/fallback and bounded table serialization.
- Added a browser test for nested lists, merged table cells and speaker-note rendering.
- Updated source contracts to ensure internal extraction-method details are not exposed to students.
