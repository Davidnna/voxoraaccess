Platform policies

Cookie notice

Last updated: 31 October 2026

This notice explains the browser storage used by the current Voxora Access application.

Current implementation: The Flask application uses a session cookie to maintain sign-in state and a CSRF token in the session to protect form submissions. This prototype does not currently describe or provide an analytics or advertising-cookie consent interface.

Essential session cookie

The application uses Flask's session mechanism to remember that you are signed in and to maintain security-related session information. The cookie is configured as HTTP-only and SameSite=Lax; the Secure flag is enabled when the application is configured for HTTPS.

Browser speech features

The reading view uses the browser's built-in speech synthesis interface when available. Speech voices and processing are controlled by the browser and operating system. This feature is not described as a cookie.

Managing cookies

You can use your browser settings to inspect, block or delete cookies. Blocking essential session cookies may prevent sign-in and other account features from working properly.

Changes

If analytics, embedded third-party services or other non-essential storage are added, this notice and any required consent controls should be updated before those technologies are enabled.
