Privacy notice

Draft notice for this prototype. Review before launch.

Information stored

Voxora Access stores submitted name and email, password hash, resource metadata and uploads, extracted text where available, library references and sharing relationships.

Public and private resources

Public resources can be discovered by visitors. Private resources are intended for their owner and explicitly shared accounts. Do not upload sensitive or copyrighted materials without permission.

Processing

Text extraction runs locally using installed Python libraries when available. Browser speech synthesis behaviour and processing depend on browser and operating system.

Retention and security

Owners can delete uploaded resources. Account deletion, self-service export and defined retention procedures are not implemented. This prototype is not security audited. Configure HTTPS, backups, monitoring, malware scanning and a contact address before launch.

This is not legal advice or a compliance certification. Tailor the notice to actual hosting and applicable law.
