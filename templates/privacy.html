Platform policies

Privacy notice

Last updated: 31 October 2026

This notice explains how Voxora Access handles information when you browse the platform, create an account, upload resources or use sharing and reading features.

Operator details must be completed before public launch. The operator should add its legal name, contact address, privacy contact and the actual hosting/provider details. This draft is based on the current application code and is not a legal compliance certification.

1. Information collected

  • Account information: name, email address, password hash and account creation timestamp.
  • Resource information: title, description, original filename, file type, MIME type, file size, visibility setting, upload timestamp and a SHA-256 file digest.
  • Uploaded content: file bytes and extracted text where extraction is supported.
  • Library and sharing information: saved resource references, resource ownership and the account identifiers involved in private sharing.
  • Session and security information: session cookie contents and form security token used to maintain sign-in and protect form submissions.

2. How information is used

Information is used to create and authenticate accounts, store and display resources, search materials available to signed-in members, enforce resource access permissions, provide library and sharing features, prevent some duplicate uploads, protect forms and operate the service.

3. Public and private resources

Resources marked public are discoverable only by signed-in Voxora members. Signed-out visitors cannot access uploaded resource details, previews, downloads or extracted text. Private resources are intended for the owner and accounts the owner explicitly shares them with. Choose visibility carefully. Do not upload confidential, sensitive or personal information unless you have authority and understand the consequences.

4. Storage and service providers

The current application stores account data, resource metadata, extracted text and uploaded file bytes in a PostgreSQL database. The project is configured for a hosted PostgreSQL service and Render web hosting. Hosting, database and infrastructure providers may process information to provide their services. The operator should identify the actual providers, locations, contractual safeguards and any international transfers before launch.

5. Passwords and security

Passwords are stored as password hashes rather than plain text. The application configures HTTP-only and SameSite=Lax session cookies and supports the Secure cookie flag when HTTPS is enabled. No online service can guarantee absolute security. This prototype has not been independently security audited and does not currently provide account deletion, self-service data export, password reset or malware scanning.

6. Cookies and browser speech

The application uses an essential session cookie for sign-in and session security. See the Cookie Notice. The reading view uses browser speech synthesis when supported; available voices and processing are controlled by the browser and operating system. Voice input uses the browser's Web Speech recognition service, whose audio processing is controlled by the browser and its provider. Voxora's additional echo-cancellation and voice-activity monitor is processed locally in the browser and is not uploaded to the Voxora backend.

7. Retention and deletion

Uploaded resources can be deleted by their owners through the application. Account deletion and a self-service retention schedule are not currently implemented. Database backups and provider-level retention may persist for periods determined by the operator and providers. The operator must document and apply an appropriate retention and deletion process before public launch.

8. Your choices and privacy requests

You can choose whether a resource is public or private, remove saved library references and delete resources you own. For access, correction, deletion or other privacy requests, contact the platform operator using the Contact page. The operator must publish a monitored privacy contact before launch and respond in accordance with applicable law.

9. Children and educational use

The platform is designed for university learning use. It is not designed as a service for children. Do not submit another person's information unless you have an appropriate lawful basis or authorization.

10. Changes

This notice may change as the platform's features, providers and data practices change. The current version and its update date will be published here.

Important: The operator should have this notice reviewed against the Nigeria Data Protection Act 2023 and any other laws that apply to its actual operations before opening the platform to the public.
